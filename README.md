# 🧀 Cheesebound RPG

**An Earthbound-inspired Classic Fantasy Adventure**

A quirky, humorous text-based RPG where medieval fantasy meets Earthbound vibes:
- Psychic powers in a world of swords and sorcery
- Weird enemies (like possessed cheese wheels or angry tax collectors)
- Emotional stories, friendship, and absurdity
- Lots of cheese references

## Features
- Character creation (Warrior, Mage, Psychic, Thief)
- Dynamic turn-based combat with funny skills
- Exploration in towns, dungeons, and weird locations
- Quests with branching stories
- Inventory, equipment, and leveling up
- Save / Load system

## Quick Start
```bash
git clone https://github.com/cheeeeeese-904/cheesebound-rpg.git
cd cheesebound-rpg
python -m pip install -r requirements.txt  # (if any)
python main.py
```
